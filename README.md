# Clima - Proyecto de Agentes de IA

Este es un proyecto de aprendizaje dedicado al desarrollo y experimentación con agentes de Inteligencia Artificial.

## Descripción
El objetivo de este repositorio es explorar la creación de agentes capaces de interactuar con herramientas externas (como servicios meteorológicos) para resolver tareas específicas de manera autónoma.

## Tecnologías
- Python
- Modelos de Lenguaje (LLMs)
- Integraciones de API
